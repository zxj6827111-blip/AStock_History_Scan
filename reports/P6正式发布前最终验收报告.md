## 3. 任务二：发布手册修正

### 3.1 风险 1：备份目录启动旧版会因相对库路径失效

**原问题**：原 `api.py` 使用 `Path(__file__).parent.parent / "database/..."`。从 `_p6_backup_*/app` 启动时，备份目录下没有 `database/`，旧版无法读库。

**修正**：回滚改为从**保留不动的原运行目录** `$OLD/app` 启动；备份只用于代码取证和启动器恢复，不用于启动。

**实测**：

```bash
cd "$OLD/app"
python3 -B -u server.py --port 8851 --no-browser
# GET / -> 200
# GET /api/stock?id=510050.SH&dataset=etf -> 510050.SH / 日主戊
# GET /api/pillar_detail?... -> 4 行，旧字段 stem_ten_god=劫财，无 ten_god 对象
```

旧版 8851 与升级前快照对照：**29/29，0 差异**（`evidence/api_compat_rollback_8851.json`）。

### 3.2 风险 2：同一个 8737 不能同时充当 OLD 和 NEW

**修正**：

1. 升级前（8737 仍为旧版）抓取 29 项响应，保存为不可变快照：
   - 文件：`evidence/api_baseline_8737_pre_p6.json`
   - 时间：2026-10-20T10:00:27+08:00
   - SHA-256：`826145a07e48bbaa78c09464c6235218927ce624e9fabd52dd327e04a8f89566`
2. 升级后把 8737 与快照逐字段比较，而不是与另一个在线旧服务比较。
3. 比较规则：旧键必须存在且值完全相等；允许新增字段；列表长度必须一致。

**实测**：

| 目标 | 结果 |
|---|---|
| 候选 8848 | 29/29，0 差异 |
| 旧版 8851（回滚演练） | 29/29，0 差异 |
