# 统一系统启动与回滚说明

- 适用：十神 V1 统一正式版（`tg-local-v1.0.0` / `tg-hidden-v1.0.0`）
- 正式端口：`127.0.0.1:8737`
- 状态：正式服务已在运行（PID 32360），本文件说明启动、停止、回滚与故障处理
- 所有命令使用绝对路径，可直接复制执行

## 0. 关键路径

```bash
ROOT="/Volumes/workSSD/software development/AStock_History_Scan"
DEV="$ROOT/bazi_month_relation_tengod_dev_v1"      # 正式代码（唯一主线）
OLD="$ROOT/bazi_month_relation_local_v1"           # 旧版目录（保留，含 A 股 SQLite）
PY="/opt/homebrew/bin/python3"
LAUNCHER_NEW="$DEV/启动十神版.command"
LAUNCHER_OLD="$OLD/启动八字历史规律查询.command"    # 现为转发入口
BACKUP="$ROOT/_p6_backup_20261019_194247"          # 旧代码取证备份
```

| 项目 | 值 |
|---|---|
| 正式启动器 | `$LAUNCHER_NEW`（默认 8737，`BAZI_PORT` 覆盖） |
| 兼容入口 | `$LAUNCHER_OLD`（转发到正式启动器，双击仍可用） |
| 正式代码目录 | `$DEV/app` |
| 数据库 | `$OLD/database/…sqlite` + `$ROOT/bazi_month_relation_etf_v1/database/…sqlite`（只读，未移动） |

## 1. 日常启动（推荐）

### 1.1 双击启动（最简单）

双击 `$LAUNCHER_NEW`（或旧的 `$LAUNCHER_OLD`，效果相同）。终端窗口保持打开即为服务运行；关闭窗口或 `Ctrl+C` 停止。

### 1.2 命令行启动

```bash
cd "$DEV" && ./启动十神版.command
```

等价于：

```bash
cd "$DEV/app" && /opt/homebrew/bin/python3 -u server.py --port 8737 --no-browser
```

### 1.3 后台常驻启动（用于无人值守）

```bash
/opt/homebrew/bin/python3 - <<'PY'
import os, subprocess
DEV = "/Volumes/workSSD/software development/AStock_History_Scan/bazi_month_relation_tengod_dev_v1"
p = subprocess.Popen(
    ["/opt/homebrew/bin/python3", "-u", "server.py", "--port", "8737", "--no-browser"],
    cwd=os.path.join(DEV, "app"),
    stdout=open(os.path.join(DEV, "evidence/prod_8737.log"), "ab", buffering=0),
    stderr=subprocess.STDOUT, stdin=subprocess.DEVNULL,
    start_new_session=True, close_fds=True)
print("pid", p.pid)
PY
```

> 注意：必须 `start_new_session=True`。普通 `nohup … &` 在某些宿主环境下会随命令会话结束被回收（P6 发布时已实际踩到一次）。

### 1.4 启动后自检

```bash
lsof -nP -iTCP:8737 -sTCP:LISTEN
curl --noproxy '*' -s -o /dev/null -w "index=%{http_code}\n" http://127.0.0.1:8737/
curl --noproxy '*' -s "http://127.0.0.1:8737/api/meta?dataset=etf"
```

`meta` 必须包含 `tg-local-v1.0.0` 与 `tg-hidden-v1.0.0`；否则运行的是旧版。

## 2. 临时预览 / 演练端口（用完即停）

```bash
cd "$DEV" && BAZI_PORT=8850 ./启动十神版.command
# 验证完
kill "$(lsof -nP -iTCP:8850 -sTCP:LISTEN -t)"
```

约束：不得常驻第二套正式服务；不得与 8737 同时作为对外入口。

## 3. 停止服务

```bash
kill "$(lsof -nP -iTCP:8737 -sTCP:LISTEN -t)"
for i in $(seq 1 20); do lsof -nP -iTCP:8737 -sTCP:LISTEN >/dev/null 2>&1 || break; sleep 0.5; done
lsof -nP -iTCP:8737 -sTCP:LISTEN || echo "8737 stopped"
```

## 4. 回滚到旧版（紧急）

触发条件：新版无法启动、API 兼容非 0 差异、黄金样本不符、数据异常。

### 4.1 停止新版

```bash
kill "$(cat "$DEV/evidence/prod_8737.pid")" 2>/dev/null || kill "$(lsof -nP -iTCP:8737 -sTCP:LISTEN -t)" 2>/dev/null
for i in $(seq 1 20); do lsof -nP -iTCP:8737 -sTCP:LISTEN >/dev/null 2>&1 || break; sleep 0.5; done
lsof -nP -iTCP:8737 -sTCP:LISTEN && { echo "端口未释放，人工处理"; exit 1; }
```

### 4.2 从原运行目录启动旧版（**不要从备份目录启动**）

```bash
cd "$OLD/app" && nohup /opt/homebrew/bin/python3 -B -u server.py --port 8737 --no-browser > /tmp/rollback_8737.log 2>&1 &
sleep 2
curl --noproxy '*' -s -o /dev/null -w "rollback_index=%{http_code}\n" http://127.0.0.1:8737/
```

- `-B` 避免向旧目录写 `.pyc`。
- 必须用 `$OLD/app`（其 `api.py` 用相对路径 `../database/…`，只有原目录结构下才成立）；`$BACKUP/app` 只是取证副本，**不能启动**。

### 4.3 恢复旧启动入口

```bash
cp -a "$BACKUP/启动八字历史规律查询.command.bak" "$OLD/启动八字历史规律查询.command"
chmod +x "$OLD/启动八字历史规律查询.command"
```

### 4.4 回滚验收

```bash
cd "$DEV"
/Users/zhangxingjin/.workbuddy/binaries/python/versions/3.13.12/bin/python3 \
  tools/api_compat_check.py \
  --baseline evidence/api_baseline_8737_pre_p6.json \
  --target http://127.0.0.1:8737 \
  --out evidence/api_compat_after_rollback.json
```

必须 `ENDPOINTS=29 TOTAL_DIFFS=0`（旧版与升级前快照完全一致）。再核对两库 SHA-256 与冻结清单第 4 节一致。

> 回滚演练证据：P6 预检阶段已在 8851 用同一方式启动旧版并通过 29/0；P6 发布后又用 `$OLD/app` 复验一次，29/0。

## 5. 故障处理矩阵

| 现象 | 原因 | 处理 |
|---|---|---|
| `启动失败：无法绑定 127.0.0.1:8737（[Errno 48]…）`，exit=1 | 端口被占用 | 查 `lsof -nP -iTCP:8737`；确认是旧版/新版/僵尸进程后处理；不得起第二实例 |
| `启动中止：A股数据库不存在…`，exit=1 | `config.py` 或 `BAZI_ASHARE_DB` 指向错误 | 检查 `$DEV/app/config.py` 绝对路径；不得改库 |
| 服务起来但 `/api/meta` 非 200 或含 `error` | 代码/配置异常 | 看 `evidence/prod_8737.log`；立即按第 4 节回滚 |
| 兼容对照 `TOTAL_DIFFS>0` | 旧字段被改动 | 立即回滚，保留 `api_compat_post_release.json` |
| 页面能开但旧字段变了 | 以兼容报告为准，不以目测为准 | 回滚 |
| 启动后进程"莫名"消失 | 启动方式未脱离会话 | 改用第 1.3 节 `start_new_session=True` |
| `meta` 没有 `tg-local-v1.0.0` | 跑的是旧版 | 检查 cwd 是否 `$DEV/app`；检查是否走错启动器 |
| 数据库报 `attempt to write a readonly database` | 有人以可写方式打开 | 本系统应始终 `mode=ro` + `query_only=ON`；检查连接配置，禁止改库 |

## 6. 明确禁止

- 不用备份目录启动服务。
- 不停止 8737 的同时在别处再起正式服务。
- 不修改两套 SQLite、不重建索引、不 `VACUUM`。
- 不删除 `bazi_month_relation_local_v1`（含正式 A 股 SQLite）。
- 不把 `evidence/`、`reports/` 复制进静态目录对外提供。
- 不覆盖既有 Git 标签。
