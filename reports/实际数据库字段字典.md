# 实际数据库字段字典（只读实测）

- 实测日期：2026-10-19
- 方式：`sqlite3 -readonly` + `PRAGMA table_info` / `sqlite_master`
- 原则：**以真实 Schema 为准**，不按 PLAN 的概念字段猜列名。两库结构基本一致，ETF 库为 67 列版本（A 股 60 列 + ETF 扩展列）。

## 1. 关键唯一键

| 表 | 主键 / 唯一键 | 说明 |
|---|---|---|
| `monthly_facts` | `PRIMARY KEY (identity_code, month_id)`（`sqlite_autoindex_monthly_facts_1`） | 一个身份一个月只有一行，是十神统计的唯一计数单元 |
| `stats_pillar60` | `PRIMARY KEY (identity_code, flow_pillar)` | 身份 × 60 柱 |
| `stats_branch12` | `(identity_code, sample_policy, branch)` 逻辑唯一 | 每身份 12 支 × 2 口径 |
| `month_relation_types` | 逻辑唯一 `(identity_code, month_id, record_kind, relation_type)` | 同月同类型一行，`event_count` 记录该月内事件数 |
| `natal_profiles` | `PRIMARY KEY (identity_code)` | 本命档案 |
| `calendar_months` | `month_id` 唯一 | 冻结节气历法，1900-02 至 2200-02 共 3,600 行 |

索引（两库相同）：

```sql
CREATE INDEX ix_mf_pillar ON monthly_facts(flow_pillar);
CREATE INDEX ix_mf_branch ON monthly_facts(month_branch, direction);
CREATE INDEX ix_mf_status ON monthly_facts(research_sample_status);
```

> 十神统计按 `identity_code` 过滤，走主键前缀；未在原库执行任何 `CREATE INDEX`。

## 2. `monthly_facts`（历史月事实，十神统计的唯一数据源）

| 列 | 类型 | 用途 | 本期是否使用 |
|---|---|---|---|
| `identity_code` | TEXT PK | 身份 | 是（过滤） |
| `month_id` | TEXT PK | 节气月 ID，如 `2006-M10` | 是（唯一计数） |
| `security_code` / `solar_year` / `month_no` | | 展示 | 是 |
| `month_branch` | TEXT | 流月地支 | 是（地支筛选） |
| `flow_pillar` | TEXT | 流月柱（两字） | 是（十神计算） |
| `flow_stem` / `flow_branch` | TEXT | 流月干支 | 是（一致性校验） |
| `flow_stem_element` / `flow_branch_element` | TEXT | 五行 | 展示 |
| `flow_year_pillar` | TEXT | 流年柱（本期不做流年十神） | 否 |
| `start_term` / `start_at` / `end_at` | | 节气与区间 | 是（展示） |
| `first_date` / `last_date` | | 首末交易日 | 是（展示） |
| `trading_days` | INTEGER | 交易日数 | 是（展示） |
| `body_return` | REAL | 当月收益（小数，0.185224 = 18.52%） | 是（均值） |
| `direction` | TEXT | `UP` / `DOWN` / `FLAT`，无 NULL | 是（涨跌平） |
| `single_day` | INTEGER | 1 = 单交易日月 | 是（ALL/EXCLUDE_SINGLE） |
| `partial_listing` / `partial_delisting` | INTEGER | 上市首月/退市末月 | 展示 |
| `quality_flags` | TEXT | 质量标记 | 展示 |
| `endpoint_basis` | TEXT | 收益口径 | 展示 |
| `raw_open` / `raw_close` | TEXT | 不复权行情证据 | 展示 |
| `qfq_open` / `qfq_close` | TEXT | 前复权展示值 | 展示（不参与统计） |
| `computation_status` | TEXT | `COMPUTED` / `BLOCKED_NO_PROFILE` | 是（状态说明） |
| `research_sample_status` | TEXT | `ELIGIBLE_UNDISPUTED` / `EXCLUDED_BOUNDARY_DISPUTED` / `EXCLUDED_NO_PROFILE` | 展示 |
| `undisputed` | INTEGER | 无争议标记 | 展示 |
| `boundary_disputed` | INTEGER | 交节争议 | 展示 |
| `profile_present` | INTEGER | 1 = 有本命档案 | 是（缺失统计） |
| `day_master_stem` | TEXT | 日主天干（与日柱天干一致） | 是（十神基准） |
| `day_master_element` | TEXT | 日主五行 | 展示 |
| `stem_ten_god` | TEXT | 流月**天干**十神（已冻结写入） | 是（统计维度，并复算校验） |
| `relation_type_list` / `candidate_kind_list` | TEXT | 关系摘要 | 展示 |
| `confirmed_event_count` / `candidate_structure_count` | INTEGER | 事件数 | 展示 |
| `benchmark_code` | TEXT | 同期基准（A 股/ETF 均为 `000001.SH`） | 是 |
| `benchmark_return` | REAL | 同期指数收益 | 是（指数比较） |
| `excess_return` | REAL | 超额收益 = 证券收益 − 基准收益 | 是（指数比较） |
| `comparison_status` | TEXT | `MATCHED` 等 | 是（benchmark_n） |
| `profile_version` / `profile_sha256` | TEXT | 档案版本/哈希 | 展示 |
| `relation_rule_version` | TEXT | 关系规则版本 | 展示 |
| `policy_version` / `policy_sha256` / `adapter_contract_version` | TEXT | 策略与适配器版本 | 否 |

**关键实测**：

- A 股 903,929 行：`direction` NULL = 0，`body_return` NULL = 0，`stem_ten_god` NULL = 54,934。
- `stem_ten_god` NULL 与 `profile_present=0` **完全相等**（54,934），且不存在"同一身份部分月有档案、部分月缺档案"的混合情况。
- ETF 75,352 行：`direction` / `body_return` / `stem_ten_god` 均无 NULL。
- `stats_pillar60` 中 `all_sample_n = up_n_ALL + down_n_ALL + flat_n_ALL` 对两库全部行成立（0 例外）。

## 3. `natal_profiles`（本命档案）

| 列 | 用途 |
|---|---|
| `identity_code` PK | 身份 |
| `profile_present` | 1 = 有档案；0 = 缺档案（禁止猜十神） |
| `natal_year_pillar` / `natal_month_pillar` / `natal_day_pillar` | 本命三柱（时柱不参与） |
| `year_stem` / `month_stem` / `day_stem` | 各柱天干 |
| `day_master_stem` | **日主天干 = 十神唯一基准** |
| `day_master_element` | 日主五行 |
| `boundary_conflict` / `boundary_day_flag` | 交节争议 |
| `archive_hour_pillar` | 档案时柱（展示，不参与） |
| `hour_pillar_used` | 固定 0 |
| `archive_polarity` / `archive_gender` / `polarity_participates` | 阴阳记账，不参与关系/十神 |
| `profile_json` / `profile_sha256` | 原始档案与哈希 |

510050.SH 实测：`乙酉 / 戊寅 / 戊寅`，`day_master_stem=戊`，`day_master_element=土`，`profile_present=1`，`archive_hour_pillar=丁巳`，`hour_pillar_used=0`。

## 4. `stats_pillar60`（60 柱冻结统计）

主键 `(identity_code, flow_pillar)`。本期只读，不新增列。核心列：

`occurrence_count`、`all_sample_n`、`exclude_single_n`、`single_day_n`、`up_n_ALL` / `down_n_ALL` / `flat_n_ALL`、`up_n_EXCLUDE_SINGLE` / `down_n_EXCLUDE_SINGLE` / `flat_n_EXCLUDE_SINGLE`、`mean_body_return_ALL` / `mean_body_return_EXCLUDE_SINGLE`、`benchmark_n`、`benchmark_mean_return`、`excess_mean`、`outperform_n`、`relation_types`、`sample_marker_ALL`、`next_occurrence`（API 计算）。

**该表没有十神列**；60 柱页的十神由 API 按 `日主 × flow_pillar` 即时计算，不改表。

## 5. `stats_branch12`（12 支冻结统计）

`(identity_code, sample_policy, branch)`；`sample_policy` 为 `ALL` / `EXCLUDE_SINGLE`。统计列：`n`、`up_n`、`down_n`、`flat_n`、`up_frequency`、`mean_return`、`median_return`、`single_day_n`、`valid_sample_n`、`main_relations`、`benchmark_n`、`excess_mean`。

**该表没有十神列**；12 支汇总不强行加"唯一十神"。

## 6. `month_relation_types`（月 × 关系类型，已聚合）

`identity_code, month_id, record_kind, relation_type, flow_pillar, month_branch, solar_year, positions, event_count, direction, body_return, single_day, undisputed, boundary_disputed, research_sample_status`。

用途：关系筛选与关系月明细。关系筛选用 `EXISTS`，不 join，避免一个月命中多关系后重复计数。

## 7. `calendar_months`（冻结节气历法）

`month_id, solar_year, month_no, year_pillar, month_pillar, month_branch, start_term, start_at, end_at, stem_element, branch_element, calendar_version`。范围 1900-02-04 至 2200-02-04，3,600 行。

当前/未来流月的干支与十神**只读此表**，不新写"公历整月"或"00:00 换月"逻辑。

## 8. 旧统计口径（必须沿用）

| 指标 | 旧口径 | 十神统计沿用方式 |
|---|---|---|
| `n` | 该身份该柱全部正式月 | 该十神组全部有十神的历史月 |
| 上涨占比 | `up_n / all_sample_n`，平盘计入分母 | `up / n`，平盘计入分母 |
| 平均涨跌幅 | `AVG(body_return)`，无值不按 0 填 | `AVG(body_return)` + `return_n` |
| 单交易日 | `single_day=1`；`EXCLUDE_SINGLE` 排除 | 同一 `single_day` 字段 |
| 指数比较 | `benchmark_n=SUM(comparison_status='MATCHED')`，`AVG(excess_return)` | 完全相同 |
| 缺档案 | `profile_present=0`，不参与十神 | 单独计入 `unavailable.missing_profile`，不设第 11 类 |

## 9. 本期明确未使用的字段/能力

- `flow_year_pillar`（流年十神未做）
- `archive_hour_pillar`（时柱不参与）
- `archive_polarity` / `archive_gender`（大运未做）
- 任何 `stats_*` 表的写操作
- 任何 `CREATE TABLE` / `CREATE INDEX` / `INSERT` / `UPDATE` / `DELETE`
