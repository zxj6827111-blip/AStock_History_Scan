# 十神规则版本说明（tg-local-v1.0.0 / tg-hidden-v1.0.0）

- 生效范围：`bazi_month_relation_tengod_dev_v1` 独立开发副本
- 规则文件：
  - `app/rules/ten_god_reference_v1.json`（100 格冻结映射，校验夹具）
  - `app/rules/ten_god_hidden_stems_v1.json`（12 支藏干，`tg-hidden-v1.0.0`）
- 代码：`app/ten_god_rules.py`（纯函数）、`app/ten_god_service.py`（受控对象）

## 1. 唯一基准

```
day_master = natal_profiles.day_master_stem = 日柱天干
流月天干十神 = ten_god(day_master, 流月天干)
流月藏干十神 = ten_god(day_master, 流月地支的每一个藏干)
```

- 不使用年干、月干、流年干作为十神基准。
- 不因冲合命中的本命柱位改变基准。
- 缺档案或日主非法 → `UNAVAILABLE_PROFILE`，不填任何推断值。

## 2. 推导算法（不是查表）

运行时由五行生克 + 阴阳推导，10×10 共 100 组：

| 关系 | 同性 | 异性 |
|---|---|---|
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀 | 正官 |
| 生我 | 偏印 | 正印 |

五行表：甲乙木、丙丁火、戊己土、庚辛金、壬癸水；阳干甲丙戊庚壬，阴干乙丁己辛癸。
相生：木→火→土→金→水→木；相克：木→土→水→火→金→木。

**与冻结映射的关系**：`ten_god_reference_v1.json` 是从
`v13_shadow_ready_20261018/release_candidate/rules/V121_verified_reference.json`
的 `ten_god_day_master_to_flow` 逐项复制的 100 组只读副本，仅用于交叉校验；
运行时结果由上述公式产生。服务启动时强制校验，若出现任何不一致即拒绝启动（fail-closed）。

实测：**100/100 一致，0 处冲突**（见 `evidence/p1_unittest.log`、启动日志）。

## 3. 藏干规则

- 版本：`tg-hidden-v1.0.0`
- 12 支全覆盖，顺序即源顺序，index 0 = 本气。
- 两支：本气 / 其他藏干；三支：本气 / 其他藏干1 / 其他藏干2。
- **无权重、无吉凶、无合成评分。**
- 详细来源与流派差异见《藏干口径差异表.md》。

## 4. 返回对象契约

```json
{
  "status": "OK",
  "rule_version": "tg-local-v1.0.0",
  "hidden_rule_version": "tg-hidden-v1.0.0",
  "day_master": "戊",
  "flow_pillar": "己亥",
  "stem": {"stem": "己", "element": "土", "yinyang": "阴", "ten_god": "劫财"},
  "hidden_stems": [
    {"order": 1, "role": "本气", "stem": "壬", "element": "水", "yinyang": "阳", "ten_god": "偏财"},
    {"order": 2, "role": "其他藏干", "stem": "甲", "element": "木", "yinyang": "阳", "ten_god": "七杀"}
  ],
  "hidden_summary": "壬·偏财 / 甲·七杀",
  "computed_from": "day_master_and_flow_pillar",
  "prediction": false
}
```

禁止字段：`weight`、`good_or_bad`、`stock_direction_prediction`、`score`。测试已断言不出现。

## 5. 状态语义

| 状态 | 含义 | 返回 |
|---|---|---|
| `OK` | 日主合法 + 流月柱合法 | 完整十神对象 |
| `UNAVAILABLE_PROFILE` | 无本命档案 / 日主非法 | `stem=null`，`hidden_stems=[]`，原因可读 |
| `INVALID_PILLAR` | 非两字、非法干支、阴阳不配（非六十甲子） | 同上，附原因 |

## 6. 版本变更纪律

- 任何藏干顺序、十神映射、角色命名的改动都必须提升版本号，并同时更新：
  - 规则 JSON 的 `rule_version`
  - 《藏干口径差异表.md》
  - 本文件
- 旧版本号不得复用；报告与 API 必须回显当前版本。
- 本版不引入大运、流年、时柱、原局十神，也不引入任何权重。
