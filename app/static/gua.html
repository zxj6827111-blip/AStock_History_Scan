起卦公式（与参考系统一致，零改动）：四价四舍五入保留 2 位 → 逐位数字求和；上卦 = 开数和 mod 8、下卦 = 收数和 mod 8、动爻 = (高数和 + 低数和) mod 6（余 0 取模数）；1乾 2兑 3离 4震 5巽 6坎 7艮 8坤。卦辞 / 爻辞 / 变卦 / 操作信号来自冻结知识库 bagua_384.json。
窗口口径：流月按节气交节时刻，09:30 归属（交节在 09:30 前归当日，之后归次日）；旬 = 第 1–10 / 11–20 / 21–月末自然日；段 = 第 1–5 / 6–10 / 11–15 / 16–20 / 21–25 / 26–月末自然日。开 = 窗内首根开盘，高 / 低 = 窗内极值，收 = 窗内末根收盘。
状态：已走完 = 定卦；进行中 = 动态卦（标「未定」，随后续K线变动）；未来 = 无卦；缺数据 = 不足不Cast。
100%段卦象：在「100%段」页点开任意段的抽屉查看（本段 + 历次同段各铸一卦）。段在 88 格小时线上定义，但小时线无高/低价，故段卦按段所跨交易日的日线 raw OHLC 铸（开=首日开、高=区间最高、低=区间最低、收=末日收），与月/旬/六段同口径。
